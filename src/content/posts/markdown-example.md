这是一篇用于本地预览的示例草稿。`draft: true` 会让文章从正式网站中排除；公开 GitHub 仓库中的源文件仍是公开的，请勿存放私密内容。

## 开始一篇文章

在 `src/content/posts/` 新建英文短横线文件名，例如 `a-small-idea.md`。文件名就是文章地址的一部分，发布后尽量保持不变。

```yaml
---
title: '一个小小的想法'
description: '用一句话说明文章的内容。'
pubDate: 2026-10-02
tags: ['随笔']
draft: true
---
```

文章标题会自动渲染为一级标题，正文从二级标题开始。准备发布时，将 `draft` 改为 `false`，再提交到仓库。

### 正文与强调

普通段落会使用适合中文阅读的行高。可以用 **粗体** 突出重点，用 *斜体* 轻轻强调，用 `inline code` 展示短命令。

## 代码块

注明语言后会自动高亮，代码块右上角提供复制按钮。较长的行会在代码块内部横向滚动。

```typescript
function greet(name: string): string {
  return `你好，${name}。欢迎开始新的记录。`;
}

console.log(greet('世界'));
```

## 表格与列表

| 字段 | 用途 | 是否必填 |
| --- | --- | --- |
| title | 文章标题 | 是 |
| description | 列表摘要和页面描述 | 是 |
| pubDate | 发布日期，格式为 YYYY-MM-DD | 是 |
| updatedDate | 最后更新日期 | 否 |
| tags | 文章标签 | 否 |
| draft | 是否草稿，默认 false | 否 |

1. 在本地写下内容。
2. 用开发服务预览文章。
3. 构建并检查正式网站。
4. 提交修改，自动发布。
