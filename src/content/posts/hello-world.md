你好，欢迎来到我的博客。

这是第一篇记录。没有宏大的开场，先给文字找一个安静的地方。

## 为什么开始写

很多想法出现得很快，消失得也很快。遇到一个有趣的问题，读到一句值得停下来的话，或者终于弄明白一段代码——如果不写下来，过一阵子，往往只剩下一个模糊的印象。

所以，把它们留下来。

> 写作不一定是为了给出答案，也可以只是把问题看得更清楚。

## 这里会记录什么

这个博客围绕三个简单的关键词展开：

- **技术**：探索的过程，解决问题的思路，以及可以复用的小经验。
- **记录**：阅读、日常观察，还有偶然遇见的好东西。
- **思考**：一些尚未定型的观点，允许它们随着时间改变。

文章不必很长，也不必每次都有结论。一段清楚的说明，一个具体的例子，都值得占据一点空间。

## 慢慢积累

如果把这个小站写成一段代码，大概是这样：

```typescript
const journal = {
  stayCurious: true,
  keepWriting: true,
};

console.log('Hello, world.');
```

比起一次写下很多，更想让这里成为一个可以持续回来的地方。遇到新的理解，就补充；发现过去的疏漏，就修正。

你可以从[标签](/tags/)寻找感兴趣的话题，也可以通过 [RSS](/rss.xml)订阅更新。
